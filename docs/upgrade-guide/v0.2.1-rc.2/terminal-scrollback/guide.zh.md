# 终端对话使用原生滚动历史

[English](guide.md) | 中文

## 变更

`dsh tui` 直接在启动目录的工作区中开始新对话，不再先打开对话选择器。界面在终端的普通屏幕中渲染，支持原生滚动历史，并以就地提问替代全屏弹窗。Enter 发送消息，Shift+Enter 换行。模型工作期间，固定面板显示最新的工具调用及其说明；之后每段连续调用折叠为一行摘要，例如 `12 tool calls · 1 failed`。不显示推理内容和正常的轮次结束；完整参数和输出通过 `/tools` 查看。对话标识、目录和 Web 地址从顶部标题移到底部状态行的右侧，其中不含浏览器登录链接，因为它相当于密码；用 `/web` 显示。Ctrl-C 停止生成，空闲时清空编辑框，连按两次退出。

## 迁移

1. 运行 `dsh tui` 开始新对话，或继续使用 `dsh tui --session <id>` 恢复指定 Session。已有的同目录工作区会被复用。
2. 使用 `/resume` 或 Ctrl-R 搜索历史对话。使用终端自身的滚动历史查看较早输出。
3. 使用 `/tools` 或 Ctrl-O 查看工具详情，使用 `/help` 查看命令。输入 `/` 补全命令，输入 `@` 补全项目文件路径。
4. 如果脚本或习惯曾从顶部标题读取登录链接或对话标识，改用 `/web`，对话标识现在位于底部状态行。
5. 确认输入区显示 `Enter send · Shift+Enter new line`。无需迁移 Session 数据。
